## 3. 大模型在项目中的作用 ✅（独立字段）

**直接复制以下内容：**

> **一、大模型在本项目里做三件事，以及刻意不做的两件事。**
>
> **做（1）非结构化信息提取。** 从财报新闻稿、电话会议摘录、SEC 文件节选、分析师报告、宏观数据稿这类自由文本里，抽出结构化字段：指标名（EPS / Revenue / CPI y/y / NFP…）、一致预期、实际值、预期差幅度、**指引立场**（raise / lower / reiterate / **withdraw**）、语气与不利语言命中。其中「指引撤回」与「指引下调」是完全不同的信息，前者意味着管理层主动放弃可预测性，在打分里惩罚最重 —— 这是纯关键词匹配容易做错、而语言模型有优势的地方。
>
> **做（2）信号推理与表述。** 起草卡片的 claim（主张）、bear case（系统自己写的反方观点）、以及 invalidation（失效条件的自然语言表述）。**注意：模型起草的是"表述"，不是"事实"。**
>
> **做（3）自然语言理解（LUI 路由）。** 把中英文问题（例如「周末休市期间 rToken 怎么定价」）路由到 7 个信号频道中的一个或多个，并推导需要哪些数据意图（quote / news / earningsCalendar / analystEstimates / signal:sentiment-analyst / signal:macro-analyst）与哪些 ticker。当前生产路径用词典 + 规则实现（确定性、可测试、零成本），LLM 路由作为可选增强。
>
> **刻意不做（1）模型不产生未经核验的数字。** 这是本项目的架构核心 —— **证据账本（Evidence Ledger）**。卡片里每一个数字都必须对回一个出处：文档的**字符偏移**、数据快照的**字段路径**、或一段**可被引擎重新执行的 recipe**（例如 `gap-study on SPY`，引擎会真的重跑一遍看能否复现卡片里的数字）。三种裁决 pass / fail / unverifiable：头条证据 fail → **整张卡进隔离区，永不发布**；unverifiable → 不隔离但**扣 corroboration 分并在卡片上如实标注**。模型输出的数字**不享有豁免权**，和规则路径走同一个账本、同一套打分。
>
> **刻意不做（2）模型不决定是否发布。** 发布由五因子加权打分（surprise 0.30 / corroboration 0.22 / asymmetry 0.20 / tradability 0.18 / freshness 0.10）与 45/100 门槛决定，**每个因子都返回一句可审计的书面理由**。此外 `hydrate()` 会**强制钳制模型的越界输出**：非法的 direction / horizon / instruments / conviction 被改写成合法值，超长 quote 被截断 —— 有专门的测试钉住这个行为。
>
> **二、架构：双抽取器 + 对账。** 确定性规则抽取器与 LLM 抽取器并行运行，由 `src/extract/index.mjs` 对账去重。**不配任何 key 时系统走纯规则路径，完整可运行**（179 个测试全部基于这条路径，`npm run validate` 60 项检查全绿）。这是刻意的：一个无法在没有模型时运行的投研工具，你没法测量它的模型部分究竟贡献了什么。有了确定性基线，LLM 路径才是可度量、可对比、可回退的增量。
>
> **三、用了哪些模型 / 接口。** 模型层是 **OpenAI 兼容端点**，可插拔：默认 `gpt-4o-mini`；通过 `PRISM_LLM_BASE_URL` / `PRISM_LLM_API_KEY` / `PRISM_LLM_MODEL` 三个环境变量切换到任意兼容模型。数据层接 **Bitget MCP Server**（`https://agent.bitget.com/mcp`，美股/ETF 行情、财报日历、分析师预期）与 **Bitget Signal Skills**（sentiment-analyst、macro-analyst），三种数据模式 `auto / live / offline`，每个数据快照都标注 origin，可追溯是实时端点还是录制 fixture。价格数据来自 Nasdaq 公开 chart API（25 symbols / 41,386 根真实日 K）。
>
> **四、大模型的实际贡献，用一个可观测的例子说明。** 同一周末、同一条新闻逻辑，两个标的：SPY 在价格库里有 44 个可比跳空样本，其计算型证据被账本**重新执行并复现**（✅ pass），corroboration 96，总分 **58.3 → 发布**；ASTR 没有价格序列，gap-study recipe **无法复算**（⚠️ unverifiable），corroboration 掉到 **70.3**，总分 **44.9 → 低于 45 门槛，不发布**，并在卡片上用自然语言写明「无可比历史跳空，无实证先验，请按结构性而非统计性理解」，风险条目改为「跳空幅度无锚，减半仓位或不做」。**系统在拿不到证据时会主动降分并闭嘴 —— 这就是"用大模型生成观点"和"用大模型生成可问责的观点"的区别。**
